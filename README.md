# Computational Physics Solutions

My solutions to exercises from computational physics textbooks, written in Python.

## Books

- **Mark Newman, *Computational Physics*** — sample chapters, programs and exercises are freely available on the [author's website](https://websites.umich.edu/~mejn/cp/chapters.html).
- **Alex Gezerlis, *Numerical Methods in Physics with Python*** — problems from the end of each chapter.

Problem statements belong to the authors and are not reproduced here. Each file starts with the exercise number and a one-line description in my own words.

## Repository structure

```
newman/
    ch02/          Python programming for physicists
    ch03/          Graphics and visualization
    ch04/          Accuracy and speed
    ch05/          Integrals and derivatives
gezerlis/
    ch01/          Idiomatic Python
```

File naming: `ex<chapter>_<number>_<short_name>.py`, for example `ex2_1_ball_drop.py`.

## Requirements

- Python 3
- numpy
- matplotlib
